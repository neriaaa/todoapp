# Smart Todo App 🧠

Это продвинутое веб-приложение для управления задачами, разработанное в рамках учебного проекта. Приложение сочетает в себе функции классического списка дел (To-Do List) и Канбан-доски с возможностями аналитики.

## 🚀 Основные возможности
* **Канбан-доска:** Управление задачами через Drag & Drop между категориями (Учеба, Работа, Жизнь).
* **Интерактивная статистика:** Визуализация прогресса выполнения задач с помощью графиков.
* **Генерация отчетов:** Возможность скачать полный отчет о задачах в формате `.docx` (Microsoft Word) одним кликом.
* **Адаптивный дизайн:** Интерфейс корректно отображается на ПК, планшетах и смартфонах.
* **Темная тема:** Поддержка переключения тем для комфортной работы.
* **Уведомления:** Использование всплывающих уведомлений для подтверждения действий пользователя.

## 🛠 Технологический стек
* **Frontend:** React (версия 19+)
* **Стилизация:** CSS Modules, адаптивная верстка (Media Queries)
* **Библиотеки:** 
    * `recharts` — для визуализации графиков.
    * `docx` — для генерации отчетов в формате Word.
    * `react-hot-toast` — для всплывающих уведомлений.
    * `file-saver` — для сохранения отчетов на устройство.
